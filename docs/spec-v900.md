# spec-v900 — ISTAP skin tear classification

## What this gives you

The type, derived from the two things a nurse actually looks at — and the reminder that this is
not a pressure injury stage.

## §1 Three types, by what happened to the flap

| | |
|---|---|
| **Type 1** | No skin loss. The flap can be repositioned to cover the wound bed |
| **Type 2** | Partial flap loss. The flap cannot cover the whole bed |
| **Type 3** | Total flap loss. The bed is entirely exposed |

## §2 A skin tear is not staged like a pressure injury

This is why the tile exists. It is an **acute traumatic wound**, and calling it a "stage 2"
borrows a vocabulary built for a different mechanism. The two systems are not interchangeable,
and the documentation error travels into the care plan and the incident report. On every result.

## §3 The type describes the flap, not the depth or the cause

A type 3 is not "worse tissue"; it is a flap that is gone. On every result.

## §4 It derives the type, and checks a type that was already assigned

The two observations — is there a flap, and does it cover the whole bed — determine the type, and
the tile says which observation produced it. When a type is entered **and** the flap description
implies a different one, it says the two disagree and that the flap is what the classification is
built on. That is the case where a wrong type gets recorded and never revisited.

## §5 Two things it does not do

It does not choose a dressing — it records what was found so the next person sees the same thing
and can tell whether the flap survived. And it is not the end of the question: a skin tear is
preventable harm in most settings, so the classification starts the ask about why it happened.

## §6 Sourcing (spec-v97 gate)

- LeBlanc K, Baranoski S, Christensen D, et al. *International Skin Tear Advisory Panel: a tool
  kit to aid in the prevention, assessment, and treatment of skin tears using a simplified
  classification system.* Adv Skin Wound Care. 2013;26(10):459-476.

## §7 Posture

Decision support, not a verdict. It records a finding against a published classification. It does
not choose a dressing, and it does not stage a pressure injury.
